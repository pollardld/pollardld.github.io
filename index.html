Containerization of Ecotrust's ocean portals

I led the modernization of Ecotrust's Madrona Portal, the shared geospatial platform behind the West Coast and Mid-Atlantic Ocean Data Portals. The existing applications were tightly coupled to legacy development and deployment infrastructure, which made them difficult to maintain, reproduce, and extend.

I redesigned the platform around a reusable Docker base image and shared runtime layer, with each portal maintaining a lightweight project-specific overlay. The new architecture provides reproducible development environments, automated container publishing, standardized configuration, database backup and restoration tools, and documented cloud deployment workflows.

This work reduces duplication, separates shared platform concerns from portal-specific functionality, and creates a more maintainable foundation for supporting both existing and future data portals.

Ocean Planning Resource Center & Interactive Mapping Tool

The Mid-Atlantic Ocean Data Portal is an online toolkit and resource center that consolidates the best available ocean and coastal data and enables users to visualize and analyze ocean resources and human use information.

Coastal ocean stakeholders need access to data and map products that can inform how ocean and coastal changes will affect them – both the ocean resources they use and the sustainability of the communities in which they live.
