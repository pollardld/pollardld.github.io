### Evidence rule

Every factual claim on this site traces to a live product, public code, an independent
source, or an approved internal artifact — recorded in [EVIDENCE-LEDGER.md](EVIDENCE-LEDGER.md).
`npm run verify` fails if an unsourced claim reappears in public copy. To publish a number,
add its ledger row first, then remove its pattern from `scripts/banned-claims.txt` in the
same commit.
